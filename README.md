# First Stage TypeScript SDK

TypeScript SDK to interact with First Stage standard (ARC coming soon) ASAs on Algorand.

This SDK is used for fetching data for assets, and users, and generation of transaction groups, including general operations (applicable for swaps, sends, and claims) and freeze transactions. More group constructions will be added shortly.

It requires:

- `algosdk` v3.4.0
- `@algorandfoundation/algokit-utils` v9.1.0

> ⚠️ This documentation is currently minimal. More detailed guides and API references will be added soon.
